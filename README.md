# KT AUTOS — Parts & Accessories

A responsive, long-scroll product showcase for KT AUTOS, styled in red and black with checked-flag details.

## View the website

Open `index.html` in a browser, or enable GitHub Pages for this repository and publish from the `main` branch (root). The website is a static page and needs no build tools.

## What's included

- Responsive layout with hero, product catalog, category cards, brand highlights, contact call-to-action, and footer.
- Eight sample automotive products with placeholder USD prices.
- Working category filters, mobile navigation, and a demo cart counter/toast.
- Sample contact email and product details to replace with real business information.

**Important:** All product names, descriptions, prices, and contact details are examples. Update them before using the site as a live store. The cart is a visual demo and does not process orders or payments.
